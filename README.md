# 🐍 Snake Game

Простая змейка на чистом HTML/CSS/JS (без зависимостей и сборки) — сделана как тестовый проект для настройки GitHub Pages и своего домена.

Управление: стрелки / WASD, пробел — пауза. На телефоне — свайпы или кнопки на экране.

## Локальный запуск

Просто открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Деплой на GitHub Pages

Репозиторий публичный, поэтому Pages включается за пару кликов:

1. Зайти в **Settings → Pages** репозитория (`https://github.com/gonempxr/snake-game/settings/pages`).
2. В разделе **Build and deployment** выбрать **Source: Deploy from a branch**.
3. Branch: **main**, папка: **/ (root)** → **Save**.
4. Через 1–2 минуты игра будет доступна по адресу:
   `https://gonempxr.github.io/snake-game/`

Дальше любой `git push` в `main` автоматически обновляет сайт.

## Подключение своего домена

1. У регистратора домена добавить DNS-записи:
   - Для домена вида `example.com` (apex) — четыре **A**-записи на IP GitHub Pages:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - Для поддомена вида `snake.example.com` — одна **CNAME**-запись на `gonempxr.github.io`.
2. В **Settings → Pages → Custom domain** репозитория вписать свой домен и сохранить — GitHub сам создаст файл `CNAME` в репозитории (либо создать его вручную с доменом внутри, одной строкой).
3. Подождать, пока DNS обновится (от нескольких минут до 24 часов), и включить галочку **Enforce HTTPS** в том же разделе, когда она станет доступна — GitHub выпустит сертификат Let's Encrypt автоматически.

Проверить статус DNS можно так:

```bash
dig +short example.com
dig +short snake.example.com
```
